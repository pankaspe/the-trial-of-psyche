# The Trial of Psyche - level I.4: "The Lamp and the Razor"
# Commands (one per line, '#' starts a comment):
#   size n                  the diorama is an n x n grid; it rotates about its centre
#   column x y z0 z1        stack of blocks (covered blocks are drawn as masonry)
#   block x y z             single block (floating is fine)
#   stairs x y z dir        stairs rising toward dir (px/mx/py/my)
#   rise x y z [stairs_dir] [rock|ground]
#                           block (or stairs) raised when the sigil is lit
#                           (rock: living rock; ground: the same, its top grassy)
#   prop name x y z [dir]   decoration in cell (x,y,z); oriented props take a dir.
#                           pillar/bed/plinth/cypress/urn/brazier block the cell;
#                           statue dir (a sister in marble on a plinth, her arm
#                           raised toward dir) blocks it too;
#                           rail/wall/wallHalf/wallBattlement/fence close side `dir`;
#                           decoration only: arch [dir], vase dir (a small vase in a
#                           corner: px (+x,+y), py (-x,+y), mx (-x,-y), my (+x,-y)),
#                           sconce dir (a candle on side `dir` of the block
#                           at x y z; lit where the setting lights them), reeds dir (a clump of reeds in a corner, as the vase)
#                           mountain: pine [dir] (bent toward dir) and boulder [dir]
#                           block the cell; shrub dir and cairn dir sit in a corner
#                           forest: spruce (a fir) blocks the cell; rope dir (the
#                           hand ropes of a rope bridge) and log dir (a fallen
#                           trunk) close side `dir`
#   setting name            night (the default: the palace under the moon) |
#                           night_candles (the same, its candles lit) |
#                           deep_night (darker, candles out, clouds across the moon) |
#                           dusk (the palace at twilight, candles lit) |
#                           crag_sunset (a crag over a sea of clouds, mountains, sunset) |
#                           forest_night (the dead of night in a forest of rock pillars)
#   start|sigil x y h       (h = surface height = block z + 1)
#   amore x y h             the cell of the bed where Cupid sleeps
#   exit x y h              reaching it completes the level
#   fragment x y h          a fragment of the tale: optional, on a spot reached
#                           by a harder, optional puzzle (level_check verifies it);
#                           one line per fragment, as many as content.FRAGMENTS
#                           gives the level, in that order
#   lamp [n]                Psyche carries the lamp; n = lightings that are enough
#                           to finish (the "no wasted light" achievement)
#   candelabrum x y h dir [lit]
#                           a standing candelabrum in corner dir of the surface
#                           x y h (corners as the vase's): lit from the start, or
#                           waiting for the lamp: lit near it, the lamp lights it
#                           for good; a lit one lights the stones around it
#   voice x y h key         line spoken when Psyche first stands there; on the
#                           start cell, when the level begins
#                           (key = an i18n.Key name, case-insensitive)
#   hint x y h key          the same for a hint (controls, rules)
#   intro key               the line shown when the level begins
#   outro key               the text of the ending card at the exit
#   lawn x y z              the block at (x,y,z) has a grassy top
#   ground x y z0 z1        a column of living rock (earth, not masonry), its
#                           top block grassy
#   rock x y z0 z1          the same, bare rock on top too
#   steps x y z dir         stairs cut in the rock (as stairs, earth and grass)
#   water x0 y0 x1 y1       a river over these cells, just under the h1 surfaces
#                           (decoration: it holds nobody)
#   prologue x y h          the level opens with the prologue cutscene; the
#                           procession comes up at this cell and walks to start
# Act II (palaces that change; ./build.sh check solves them move by move):
#   crumble x y z [opt]     a cracked block: it falls once Psyche steps off it
#                           opt (also for block, phantom, veiled): rock (bare
#                           living rock instead of palace stone), ground (living
#                           rock, its top grassy), plank / plank_y (the wooden
#                           deck of a rope bridge running along x / y)
#   phantom x y z           a pale block, real only in the dark: the lamp's
#                           light (about 2.5 cells from her) dissolves it for good;
#                           the lamp cannot be lit over one
#   veiled x y z            a block hidden in the dark: the lamp shows it in gold
#                           and, as close as above, makes it real for good
#   part px py ... end      the blocks, stairs and props in between form a part
#                           that turns a quarter at a time about cell (px, py)
#   handle x y h [n]        standing there, a click on Psyche (or F) turns part n
#                           (default: the last part) counter-clockwise from above
#   rest x y h              a brazier: lit by passing, R brings Psyche back to the
#                           last one lit, the palace as it was then
#   oil seconds             the lamp's oil (default 14)
#   mechanic name           the level introduces crumble|phantom|veiled|handle: a
#                           card presents it at the start and its pieces glow
# Illusions: in the dark two surfaces are joined when they look joined in the
# current view: (x',y',h) touches (x'+dx+k, y'+dy+k, h+k) in view coordinates,
# provided the edge where they touch is visible on both tops (a top half
# covered by a nearer cube still shows the edges of its other half) and no
# rail closes the side. A seamless illusion runs toward the camera onto nearer pieces.
# Check every design with: ./build.sh check assets/levels/<file>
#
# The level: the dead of night, the candles out, clouds over the moon. Psyche
# carries the lamp for the first time. In the dark the palace still answers to
# its turns (a flight hidden from the first view, a seam to the west terrace);
# the stairs under the portico hide from every view: only the lamp's light
# finds them. From the balcony a seam (view 1) joins the seal's pillar; the
# lamp lit on the seal raises a bridge of five stones to the gallery, and from
# the gallery the first view joins Cupid's chamber, where the lamp is lit.
# The fragment: from the west walk, four pillars, each joined to the next by
# another view (3, 2, 1, 0).
