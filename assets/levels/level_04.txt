# The Trial of Psyche - level I.4: "The Lamp and the Razor"
# Commands (one per line, '#' starts a comment):
#   size n                  the diorama is an n x n grid; it rotates about its centre
#   column x y z0 z1        stack of blocks (covered blocks are drawn as masonry)
#   block x y z             single block (floating is fine)
#   stairs x y z dir        stairs rising toward dir (px/mx/py/my)
#   rise x y z [stairs_dir] block (or stairs) raised when the sigil is lit
#   prop name x y z [dir]   decoration in cell (x,y,z); oriented props take a dir.
#                           pillar/bed/plinth/cypress/urn/brazier block the cell;
#                           rail/wall/wallHalf/wallBattlement/fence close side `dir`;
#                           decoration only: arch [dir], vase dir (a small vase in a
#                           corner: px (+x,+y), py (-x,+y), mx (-x,-y), my (+x,-y)),
#                           sconce dir (an unlit candle on side `dir` of the block
#                           at x y z)
#   start|sigil x y h       (h = surface height = block z + 1)
#   amore x y h             the cell of the bed where Cupid sleeps
#   exit x y h              reaching it completes the level
#   fragment x y h          the fragment of the tale: optional, on a spot reached
#                           by a harder, optional puzzle (level_check verifies it)
#   lamp [n]                Psyche carries the lamp; n = lightings that are enough
#                           to finish (the "no wasted light" achievement)
#   voice x y h key         line spoken when Psyche first stands there; on the
#                           start cell, when the level begins
#                           (key = an i18n.Key name, case-insensitive)
#   hint x y h key          the same for a hint (controls, rules)
#   intro key               the line shown when the level begins
#   outro key               the text of the ending card at the exit
#   lawn x y z              the block at (x,y,z) has a grassy top
#   prologue x y h          the level opens with the prologue cutscene; the
#                           procession comes up at this cell and walks to start
# Act II (palaces that change; ./build.sh check solves them move by move):
#   crumble x y z           a cracked block: it falls once Psyche steps off it
#   phantom x y z           a pale block, real only in the dark: the lamp's
#                           light (about 2.5 cells from her) dissolves it for good;
#                           the lamp cannot be lit over one
#   veiled x y z            a block hidden in the dark: the lamp shows it in gold
#                           and, as close as above, makes it real for good
#   part px py ... end      the blocks, stairs and props in between form a part
#                           that turns a quarter at a time about cell (px, py)
#   handle x y h [n]        standing there, a click on Psyche (or F) turns part n
#                           (default: the last part) counter-clockwise from above
#   rest x y h              a brazier: lit by passing, R brings Psyche back to the
#                           last one lit, the palace as it was then
#   oil seconds             the lamp's oil (default 14)
#   mechanic name           the level introduces crumble|phantom|veiled|handle: a
#                           card presents it at the start and its pieces glow
# Illusions: in the dark two surfaces are joined when they look joined in the
# current view: (x',y',h) touches (x'+dx+k, y'+dy+k, h+k) in view coordinates,
# provided both tops are visible (no nearer cube covers them) and no rail closes
# the side. A seamless illusion runs toward the camera onto nearer pieces.
